# Rentora — Equipment Rental Platform

## Project Purpose
Rentora is a full-stack equipment rental platform where customers can browse and rent equipment, owners can manage their equipment listings, and administrators can manage platform activities.

## Live Website
https://rentora-client-xi.vercel.app

## Backend API
https://rentora-server-koem.vercel.app

## Key Features
- User registration and login.
- Three user roles: Customer, Owner, and Admin.
- Role-based access control and protected dashboards.
- Browse equipment and view equipment details.
- Add and remove favorite equipment.
- Book equipment and manage bookings.
- Stripe test-mode payment integration.
- Customer, Owner, and Admin dashboards.
- User profile page.
- Update name, phone number, address, and profile image.
- Profile photo upload.
- Responsive user interface.

Install dependencies:

    npm install

Start the development server:

    npm run dev

Open http://localhost:3000 in your browser.
